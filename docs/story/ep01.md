## Scene 1 — The Brief

- objective: Understand the project brief.
- objectiveTh: ทำความเข้าใจโจทย์ของโครงการ

### Interaction
- promptEn: What should the team clarify first?
- promptTh: ทีมควรถามให้ชัดเรื่องอะไรก่อน?

#### Choice A — "Who are the users, and what problem do they have?"
- skillTags: problem-framing, clarification
- nextScene: ep01_s2
- You communicated: คุณถามถึงผู้ใช้และปัญหาของเขา ซึ่งเป็นสองเรื่องที่โจทย์ยังไม่ได้บอก
- A natural option: "Who are we building this for, and what problem do they have?"
- Why it works: การรู้ว่าใครเจอปัญหาอะไรช่วยให้ทีมไม่สร้างสิ่งที่ไม่มีใครต้องการ และเป็นคำถามที่ใช้ได้กับทุกโปรเจกต์
- Try a pattern: "Who are the users, and what do they need?" — แทนคำ: what do they need → what is difficult for them / when does the problem happen

#### Choice B — "Which programming language should we use?"
- skillTags: solution-first
- nextScene: ep01_s2
- You communicated: คุณสนใจด้านเทคนิคและอยากเตรียมตัวสร้างงาน
- A natural option: "Before we choose the tools, could we clarify who the users are?"
- Why it works: ภาษาโปรแกรมอาจสำคัญภายหลัง แต่ยังเร็วไปเมื่อทีมยังไม่รู้ว่ากำลังสร้างอะไรให้ใคร
- Try a pattern: "Before we choose ___, could we clarify ___?" — แทนคำ: the tools / the design; the goal / the users

#### Choice C — "Can we start building today?"
- skillTags: planning
- nextScene: ep01_s2
- You communicated: คุณแสดงความกระตือรือร้นและอยากให้งานเดินเร็ว
- A natural option: "Can we spend today understanding the problem, then plan what to build?"
- Why it works: ความเร็วเป็นเรื่องดี แต่ยังไม่มี requirement หรือ evidence การเริ่มสร้างทันทีอาจต้องรื้อทำใหม่
- Try a pattern: "Can we ___ first, then ___?" — แทนคำ: talk to students / check the data; plan the work / build a prototype

#### Choice A — "What is our deadline?"
- skillTags: planning, clarification
- nextScene: ep01_s3
- You communicated: คุณถามเรื่องเวลา ทำให้ทีมรู้ว่ามีหกสัปดาห์ และ Chief จะแบ่งเป็นช่วงค้นหาปัญหา–ทดลอง–นำเสนอ

#### Choice B — "Who approves the final project?"
- skillTags: stakeholder-mapping

- A natural option: "Who will make the final decision about our project?"
- Why it works: การรู้จัก stakeholder ที่ตัดสินใจช่วยให้ทีมรู้ว่าต้องเตรียมหลักฐานแบบไหนไปนำเสนอ
- Try a pattern: "Who will ___ the final ___?" — แทนคำ: approve / review / use; project / report / design

- A natural option: "We have many ideas. How should we decide which ones to do first?"
- Why it works: การถามว่าทำทุกอย่างได้ไหมมักได้คำตอบว่า "ไม่ได้" การถามวิธีจัดลำดับช่วยให้ทีมไปต่อได้
- Try a pattern: "How should we decide which ___ to ___ first?" — แทนคำ: problem / idea; solve / test

## Business & Data Lesson
ใช้กรอบ **User → Problem → Evidence → Success** ก่อนเลือก Solution:
- **User:** ใครกำลังเจอปัญหา? (ในเรื่อง: Taku ที่เรียนห้อง 3B, Nana ที่อยู่ชมรม)
- **Problem:** ปัญหาเกิดขึ้นเมื่อไรและอย่างไร? (Wi-Fi ล่มตอนเปิดชีทเรียน, ประกาศมาไม่ทัน)
- **Evidence:** มีหลักฐานอะไรสนับสนุน? (สัมภาษณ์สองคน + รายงานเก่า — ยังไม่พอ)
- **Success:** จะรู้ได้อย่างไรว่าดีขึ้น? (ทีมยังต้องตกลงกันในตอนถัดไป)

Kuro เริ่มจาก Solution (แอปแจ้งปัญหา) ส่วน Miyu เริ่มจาก User และ Problem — ทั้งสองอย่างมีค่า แต่ลำดับสำคัญ

## Sentence Patterns
1. **We need to + verb** — We need to understand the problem.
   แทนคำ: interview students / check the source / define the goal
2. **We don't know whether + clause** — We don't know whether the data is correct.
   แทนคำ: the file is safe / students need this feature / the report is complete
3. **Before we + action, we should + action** — Before we use the file, we should check its source.
   แทนคำ: build the app / talk to users; share the report / ask the data owner

## Mini Case
| ปัญหาที่ถูกรายงาน | จำนวนรายงาน |
| --- | ---: |
| Slow Wi-Fi | 45 |
| Long cafeteria lines | 30 |
| Missing announcements | 15 |
| No wheelchair access to one classroom | 6 |
| Other | 4 |

ผู้บริหารบอกว่า: "Slow Wi-Fi has the most reports, so it must be our first priority."

**คำถาม (ตอบเป็นภาษาอังกฤษ):**
- What else should we ask?
- Do we know how the students were selected?
- Does the number of reports show the severity of the problem?
- Who is affected by the access issue?

**แม่แบบช่วยตอบ:**
- "The data shows that ___."
- "However, we don't know whether ___."
- "Before we decide, we should ___."

**คำตอบตัวอย่าง:** "The data shows that Wi-Fi received the most reports. However, we don't know how many students were affected by each problem. Before we decide, we should compare both impact and severity."
