# Design plan — Project SIGNAL

ใช้ร่วมทุก milestone ที่มี UI (M3–M6) ยึด `docs/spec/06-screens-ux.md` เป็นหลักเมื่อขัดกัน

## Subject
เว็บเกมคดีลึกลับในโรงเรียนเทคโนโลยี ผู้เล่นคือนักเรียนไทยที่กำลังจะฝึกงาน งานหลักของ UI คือทำให้ "อ่านบทสนทนาภาษาอังกฤษแล้วอยากรู้ต่อ" โดยไม่รู้สึกเหมือนทำข้อสอบ

## Color (tokens ใน `src/styles/tokens.css`)
- **Night navy** `#0f1f3a` — พื้นหน้าเกม บรรยากาศห้องเรียนหลังเลิกเรียน
- **Signal teal** `#179d94` — เส้นสัญญาณ/สถานะเล่นได้/ปุ่มหลัก
- **Paper cream** `#fbf7ee` — พื้นที่อ่านเท่านั้น (การ์ดตอน, กล่องบทสนทนา, เนื้อหา intro) เหมือนเอกสารคดีบนบอร์ด
- **Coral** `#e2674f` — เบาะแส/สิ่งที่ต้องสังเกต (ใช้น้อย)
- **Amber** `#e3a72f` — focus ring และไฮไลต์คำศัพท์

## Type
- **IBM Plex Sans Thai** ทั้งไทยและอังกฤษ (ครอบครัวเดียว ดูเป็นเทคโนโลยีแต่ไม่แข็ง) — fallback เป็น system Thai fonts เมื่อออฟไลน์
- Display: 700, ตัดบรรทัดแน่น; เนื้อหา: 400, line-height 1.6, บรรทัดไม่เกิน ~70 ตัวอักษร
- ไม่ใช้ตัวพิมพ์ใหญ่ทั้งคำเป็น label, ไม่ใช้ monospace ทำ label, ไม่ใส่ "→" ท้ายปุ่ม

## Layout
```
Home (mobile ↓ / desktop เหมือนกัน กว้างสุด 46rem)
┌──────────────────────────────┐
│ Project SIGNAL   [คำศัพท์][ตั้งค่า] │  header บาง
│                              │
│ Angels of Deceit             │
│ PROJECT SIGNAL  (ใหญ่)        │  hero + เส้นคลื่นสัญญาณ SVG
│ ~~~~~~~~~~~~~~~~──────        │  ← สิ่งเดียวที่ "กล้า"
│ pitch ไทย 1–2 บรรทัด · A2–B1   │
│ [ เริ่ม Episode 1 ]           │
│                              │
│ ● 1  A Problem Without...    │  เส้นสัญญาณแนวตั้ง = ลำดับตอนจริง
│ │    การ์ดกระดาษ cream         │  (ตัวเลขใช้ได้เพราะเป็นลำดับจริง)
│ ○ 2  ...  ปลดล็อกเมื่อจบ EP1   │
│ ┆ 4–12 locked preview (จาง)   │
└──────────────────────────────┘
```
- Episode Intro: หัวตอน + สรุปไทย → "สถานการณ์/เป้าหมาย" → role ที่ได้เรียน → ตัวละครในตอน (avatar วงกลม) → คำศัพท์ (en/th) → ปุ่ม "เริ่มตอนนี้" ติดล่างบนมือถือ
- ชิดซ้ายทั้งหมด ยกเว้นไม่มี

## Principles
1. **กระดาษบนบอร์ดมืด** — ข้อความยาวอยู่บนพื้น cream เสมอ พื้น navy มีแค่หัวเรื่องและการนำทาง
2. **สัญญาณ = ความคืบหน้า** — เส้น teal เชื่อมตอนที่เล่นแล้ว/เล่นได้, เส้นประจางสำหรับตอนที่ล็อก
3. **สถานะต้องมีคำเสมอ** — ไอคอน + ข้อความ (เล่นได้ / จบแล้ว / ปลดล็อกเมื่อจบ EP… / เร็ว ๆ นี้) ไม่พึ่งสีอย่างเดียว
4. **motion ครั้งเดียว** — เส้นคลื่นใน hero วาดตัวตอนโหลด; ที่เหลือมีแค่ transition จากการกด และปิดเมื่อ prefers-reduced-motion
5. ปุ่มสูง ≥ 44px, focus ring amber ชัด, ไม่มี scroll แนวนอนที่ 320px
