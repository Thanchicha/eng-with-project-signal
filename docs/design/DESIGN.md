# Design plan — Project SIGNAL ("Cage of Data")

ใช้ร่วมทุกหน้าจอ อ้างอิงอารมณ์ภาพจาก key art ที่ผู้ใช้ให้ (Kuro กับ Miyu ในโรงเรียนยามค่ำคืน โทนม่วงกลางคืน + ชมพูนีออน)
ใช้เฉพาะ **สีและอารมณ์** — ข้อความบนโปสเตอร์นั้นเป็นเนื้อเรื่องสาย SS1 (ย้ายโรงเรียน, ตามหาครอบครัว, CAGE เป็น AI) ซึ่งขัดกับ AU ใน brief จึงไม่นำภาพหรือข้อความนั้นมาใส่ในเกม

## Subject
เกมฟัง-พูดภาษาอังกฤษในคดีข้อมูลของโรงเรียน CAGE บรรยากาศ data / mystery / cyberpunk / suspense แต่ยังเป็นมิตรกับนักเรียน

## Color (tokens ใน `src/styles/tokens.css` ผ่าน WCAG AA ทุกคู่ข้อความ)
- **Night** `#140b23` / `#221539` / `#3a2758` — ท้องฟ้ากลางคืนและแผง HUD
- **Signal pink** `#f25aa3` (บนพื้นมืด) / `#b02d73` (ปุ่ม + ตัวอักษรบนกระดาษ) / glow `#ff7ab8`
- **Lilac paper** `#f9f4fc` — พื้นที่อ่านบทพูดและบทเรียนเท่านั้น
- **Rose** `#ff5c86` / `#a8264b` — ERROR, คำเตือน, ตอบยังไม่ใช่
- **Glow** `#ffc6e6` — ไฮไลต์และ focus ring บนพื้นมืด (บนกระดาษใช้ `#b02d73`)

## Type
- **IBM Plex Sans Thai** สำหรับเนื้อหาไทย/อังกฤษทั้งหมด
- **Cormorant Garamond** (serif display) เฉพาะชื่อเรื่องภาษาอังกฤษขนาดใหญ่ เลียนตัวอักษร "Angels of Deceit – Cage of Data –" ใน key art พร้อม glow ชมพูอ่อน

## Motifs (ใช้แบบพอดี)
1. **ท้องฟ้ากลางคืน** — พื้นหลังมีแสงพระจันทร์ชมพูมุมขวาบน + เส้นกริดข้อมูลจาง ๆ
2. **HUD panel** — แผงมืดโปร่งแสงขอบนีออนบาง (`.hud`, แผงเสียง, ตัวเลือก, การ์ดตอนที่ล็อก)
3. **Glow** — ปุ่มหลักไล่สีชมพู-ม่วงมีเงาเรือง; เส้นคลื่นสัญญาณใน hero เรืองแสง
4. **กระดาษ lilac** — ข้อความยาวยังอยู่บนพื้นสว่างเสมอเพื่อให้อ่านง่าย

## Principles
1. อ่านง่ายมาก่อนบรรยากาศ: ข้อความยาวบนกระดาษ lilac, ตัวอักษรบนพื้นมืดใช้สีที่ contrast ≥ 4.5:1
2. สถานะต้องมีคำเสมอ ไม่พึ่งสีอย่างเดียว
3. motion น้อย: เส้นคลื่นวาดครั้งเดียว, ปิดเมื่อ prefers-reduced-motion
4. ปุ่มสูง ≥ 44px, ไม่มี scroll แนวนอนที่ 320px
5. ภาพประกอบในอนาคตต้องไม่มีข้อความฝังในภาพ (ข้อความให้ UI แสดง) — ดู `docs/art/ART_BRIEF.md`

## ข้อห้ามเรื่องคะแนน (brief Final)
- mockup มีแถบ Pronunciation / Fluency / Accuracy — **ห้ามใช้** แทนด้วย `PracticeMeter` 3 ขั้น: ฟังต้นแบบ / พูดครั้งแรก / พูดด้วยคำตัวเอง (เติมเมื่อทำ ไม่เก็บลง storage)
- XP/Level มาจากการลงมือทำเท่านั้น (`src/features/progress/xp.ts`) ตอบผิดไม่เสีย XP และไม่มีอันดับ
- ไม่มีตัวเลขหรือสีที่สื่อว่า "ถูก/ผิด" กับการพูด; feedback ใช้หัวข้อเชิงบวก
