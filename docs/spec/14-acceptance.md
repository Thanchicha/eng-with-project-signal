## 14. เกณฑ์รับมอบ MVP (ฉบับฟัง-พูด)

ตรวจล่าสุดด้วย `tests/e2e/qa_acceptance.py` (Playwright, production build) — ผล 16 ผ่าน, 0 ไม่ผ่าน, 1 อยู่นอกขอบเขต MVP
เสียงและไมโครโฟนใน QA เป็น stub (headless ไม่มีเสียงจริง): speechSynthesis จบแต่ละบรรทัดทันทีและบันทึก rate, SpeechRecognition คืนประโยคตายตัว และนับการเริ่มฟัง
ทดสอบมือในเบราว์เซอร์จริงแล้ว: เสียง TTS ภาษาอังกฤษ 3 เสียงของ Windows เล่นครบทุกบรรทัด; ไมค์จริงทดสอบเฉพาะเส้นทางยินยอม/ปฏิเสธ (ใช้ recognizer จำลอง ไม่ได้พูดผ่านไมค์จริง)
