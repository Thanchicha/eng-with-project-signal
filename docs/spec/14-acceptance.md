## 14. เกณฑ์รับมอบ MVP (ฉบับฟัง-พูด)

ยังไม่ได้ตรวจกับเวอร์ชันฟัง-พูด — ผลตรวจรอบเดิม (ฉบับเน้นอ่าน, 2026-10-18) อยู่ใน git history

- [ ] ผู้เล่นเปิดเว็บแล้วเริ่ม Episode 1 ได้โดยไม่ต้องสมัครบัญชีหรือใส่ API key
- [ ] เล่นตั้งแต่ Before Listening จน Episode Recap ได้ครบ
- [ ] ทุกฉากหลักของ EP1 มีเสียงภาษาอังกฤษและ Listening Check ก่อนเปิด transcript ตามค่าเริ่มต้น
- [ ] ฟังเสียงซ้ำและลดความเร็วได้; เปิด transcript/คำแปลได้ทุกเมื่อ
- [ ] มี Speak Response อย่างน้อย 3 จุด ผู้เล่นพูดออกเสียงก่อนเลือก intent/phrase support; สามารถเลือก I said it หรือพิมพ์ตอบได้แม้ไม่มีไมค์
- [ ] ถ้ารองรับ speech recognition ให้ขอ permission ตอนเริ่มเท่านั้น แสดง transcript แก้ไขได้ และไม่ใช้ transcript เป็นคะแนน accent/ความเหมือนคำต่อคำ
- [ ] ทุกปุ่มเสียงและไมค์มี label, stop/cancel และสถานะชัดเจน; UI ทำงานได้ด้วย keyboard
- [ ] Kuro และ Miyu มีบทสนทนาและการกระทำที่จำเป็นต่อเนื้อหาในทุกฉากหลักของ EP1
- [ ] ผู้เล่นเปิดคำศัพท์ได้ และได้รับ feedback ภาษาไทยหลังลองฟัง/พูด ไม่ใช่แค่ correct/incorrect
- [ ] ฟังและพูด sentence pattern อย่างน้อย 3 แบบ; การเขียนเป็นทางเลือกเสริม
- [ ] Mini Case มี briefing เสียงและให้พูดสรุปได้โดยไม่ต้องใช้ AI
- [ ] เมื่อ refresh หน้า ความคืบหน้าและคำศัพท์ยังอยู่ใน browser แต่ไม่มีการเก็บเสียง/transcript ไมค์
- [ ] ตอน 2–12 แสดงชื่อ เรื่องย่อ บทบาท และ listening/speaking mission พร้อมสถานะ locked
- [ ] หน้าจอมือถือไม่มีการเลื่อนแนวนอน; ปุ่มหลักอ่านและกดได้ง่าย
- [ ] ปริศนาหลักถูกอธิบายเป็นข้อมูลทดสอบปะปน + key การ join ไม่ครบ + KPI/การเข้าถึงที่ผิดพลาด และไม่เฉลยว่าเป็นการแฮกโดยไม่มีหลักฐาน
